~~📌 Day 6: Binary Number System & Bitwise Manipulation-
~~ 🧠 Concepts Used:
1. **Bitwise AND Operator (`&`):** Performing bit-level evaluations directly on integer binary representations.
2. **Binary Property of Powers of 2:** Understanding that powers of 2 have exactly one set bit (`1`) in their binary representation (e.g., $16 = 10000_2$).
3. **Bit Unsetting Trick (`n & (n - 1)`):** Utilizing the property that subtracting 1 flips all bits after the rightmost set bit, causing `n & (n - 1)` to clear the lowest set bit to `0`.
4. **Loopless $O(1)$ Optimization:** Replacing iterative division/multiplication loops with direct bitwise conditions.

~~ 🛠️ Skills Learnt:
* Applying bitwise operators to solve numeric problems efficiently.
* Eliminating iterative loops in favor of constant-time $O(1)$ mathematical and bit-level properties.
* Guarding against boundary conditions (e.g., $n \le 0$) in bitwise logic.
